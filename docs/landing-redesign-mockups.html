What Scorpio does

1. You assign

Pick a set from a course and give students the class code.

2. Students work

One problem at a time, online, on any device.

3. It grades

Numeric and multiple-choice answers are marked on submit. Stuck students can ask for a hint, never the answer.

4. You review

Scores per student, and the mistakes the class made most, by unit.

A homework tool for physics teachers

Scorpio is built for AP Physics 1. You assign problems, students work through them with hints when they get stuck, and you see which ideas the class is missing. It is free for individual teachers.

What a week looks like

  • MondayCopy the Unit 2 set from the course and share the class code.
  • Tue – ThuStudents work. Answers are checked on submit; stuck students get a hint.
  • FridayOpen the report: "Friction drawn the wrong way, 8 of 24."

What you don't have to do

  • GradeNumeric and multiple-choice answers are graded for you.
  • Set upNo LMS connection. A class code is enough.
  • PayFree for one teacher. Departments can add a flat plan.
